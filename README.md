## Installation

**Windows**

```bash
## Windows 11/10
winget install Codryn.Codryn

## Linux(debian/ubuntu)
sudo apt install codryn
```

> [!WARNING]
> The installation above also includes the backend (`codryn`) that the desktop starts automatically.

## About

This is the desktop client of the Codryn application. Since this is still in the **Beta** stage, certain features and support have been scaled back; however, you can contribute to expanding that support—whether by submitting **Issues** to report bugs, performance problems, or other matters.

## Contributing

Contributing does not have to mean writing code. Opening an issue or reporting a bug is a real contribution and very welcome. See [CONTRIBUTING.md](CONTRIBUTING.md) for the full guide.
